## Basic

A native `<textarea>` (default `rows={6}`) in a 15px-radius card box. Pair it with a visible
label or `aria-label` — there is no built-in label.

## Sized and full width

`rows` sets the initial height; `fullWidth` makes the box track its container instead of the
fixed 481px Figma width.
