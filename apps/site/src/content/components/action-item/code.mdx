## Default set

With no `actions` prop, ActionItem renders the Figma set: delete (danger) · upload · edit ·
share. The exported `defaultActions` array is the same list, ready to extend.

## Custom actions

Each action is `{ id, label, icon, tone?, onClick?, disabled? }` — pass any ordered subset.
Icons must be 24px SVGs using `currentColor` so the tone controls the fill; the four default
glyphs are exported from `@ramsarjal-404/react`.

## Disabled action

Set `disabled` on an individual action — the native attribute removes it from the tab order
and dims it to 40%.
