## Basic rail

Each `SidebarItem` needs a stable `key`, a `label`, and an `icon` (use `currentColor` SVGs so
the active tint applies). Slot the product logo into `header` and pinned controls into
`footer`.

## Links as items

Give items an `href` to render real anchors — browser history and middle-click work, and the
active item still sets `aria-current="page"`. Disabled link items drop their `href` and set
`aria-disabled`.
