Lepide products ship plain HTML/CSS/JS — the **HTML + `lp-` classes** tab is the canonical form.
The React rendition (`@lepidus/react`) is fully controlled and adds the clamped page input and the
page-size popover behavior.

<Callout variant="info" title="Bring your own navigation logic">
  <p><code>lepidus.js</code> has no pagination behavior — the bar is pure CSS. Wire the button
  clicks, page-input commit and disabled states to your own data layer. The
  <code>lp-pagination__page-size-*</code> classes style a popover for the rows-per-page selector
  if you build one; otherwise render the current size as a plain label as below.</p>
</Callout>
