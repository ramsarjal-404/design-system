# Design Tokens

All tokens are generated from the Figma DTCG export by `npm run tokens` into
`packages/tokens/build/css/tokens.css`. **Components must consume the Component tier**
(`--component-*`) or shared space/radius/typography tokens — never primitives directly.
The swatches below render live from the loaded `tokens.css`, so this page always reflects the
current build.

## Component tier

Each component owns a `--component-<name>-*` namespace bound to semantic tokens, e.g.:

```css
--component-pagination-active-bg: var(--color-brand-primary);
--component-textfield-active-bg:  var(--color-button-secondary-bg);
--component-toast-bg-to:          var(--color-brand-secondary);
--component-dropdown-header-bg:   var(--color-button-secondary-bg);
```

See each component's docs page for its full token table. To add a token: edit
`packages/tokens/src/component.tokens.json` (alias a semantic path — never a raw hex), run
`npm run tokens`, then consume it as `var(--component-…, <resolved fallback>)`.
