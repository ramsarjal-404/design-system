# Using Lepidus without React

`@lepidus/css` delivers the design system as **plain CSS classes** — for any
page or app written in HTML/CSS/JS, with no framework and no build tool.
It is generated from the same source as the React components, so the two can
never drift apart. Every example below is **live** — rendered by the plain CSS
in this very page — and respects the theme switcher in the toolbar.

## Setup

Link one stylesheet (from `packages/css/dist/`), then write HTML:

```html
<link rel="stylesheet" href="lepidus.css" />
```

Theming: set `data-theme` on the root element — `light` (default), `dark`, or `hc`.

```html
<html data-theme="dark">
```

Class naming is BEM with an `lp-` prefix: block (`lp-button`),
modifier (`lp-button--primary`), element (`lp-button__icon-left`).

## Modal — interactive, needs lepidus.js

```html
<button class="lp-button lp-button--primary lp-button--md"
        data-lp-modal-open="add-server">Open</button>

<div class="lp-modal" id="add-server" hidden>
  <div class="lp-modal__shell lp-modal__shell--sm" role="dialog" aria-modal="true"
       aria-labelledby="add-server-title">
    <div class="lp-modal__header lp-modal__header--center">
      <h2 class="lp-modal__title" id="add-server-title">Add file server</h2>
    </div>
    <div class="lp-modal__body">
      <div class="lp-modal__fields">
        <label class="lp-modal__field-label" for="name">Name</label>
        <div class="lp-input lp-input--full-width">
          <div class="lp-input__field"><input class="lp-input__input" id="name" data-lp-autofocus /></div>
        </div>
      </div>
    </div>
    <div class="lp-modal__footer">
      <button class="lp-button lp-button--primary lp-button--md" data-lp-modal-close>Save</button>
      <button class="lp-button lp-button--secondary lp-button--md" data-lp-modal-close>Cancel</button>
    </div>
  </div>
</div>
```

`lepidus.js` handles open/close (`data-lp-modal-open` / `data-lp-modal-close`,
Escape, backdrop click), traps focus inside the dialog while open, focuses
`[data-lp-autofocus]` (or the first focusable) on open, and restores focus on
close. Shell sizes: `--sm` (520px), `--md` (680px), `--lg` (743px); use
`lp-modal__shell--inline` without the overlay for embedded panels. Also
callable from code: `Lepidus.openModal('add-server')` / `Lepidus.closeModal()`.

```html
    <div class="lp-dropdown__footer">
      <button class="lp-button lp-button--secondary lp-button--sm">Cancel</button>
      <button class="lp-button lp-button--primary lp-button--sm">Apply</button>
    </div>
  </div>
</div>
```

`lepidus.js` opens/closes the panel (trigger click, Escape, outside click).
`multi` toggles each option's `aria-checked` and check glyph; `single` writes
the chosen label into the trigger and closes. Selection changes fire an
`lp-dropdown-change` CustomEvent on the wrapper.

## Toast — JS API

```js
Lepidus.toast({
  title: 'Scan complete',
  message: 'No violations found.',
  variant: 'success',   // info | success | warning | error
  duration: 5000,       // ms; 0 = stays until closed
});
```

Stacks notifications in a fixed top-end region with the status badge, close
button, and auto-dismiss. Returns a function that dismisses the toast early.

## Tooltip — data attribute

```html
<button class="lp-button lp-button--white lp-button--md"
        data-lp-tooltip="Runs a full permissions scan">Run scan</button>
```

`lepidus.js` shows the bubble on hover and keyboard focus, positions it above
the target (flipping below when there's no room), wires `aria-describedby`,
and hides on leave/blur/Escape.

## What's covered so far

**27 components** ship as plain CSS today — everything except the React-only
specialties (ActionItem, Calendar, Charts, Filter, FolderTree, Scrollbar,
SettingsPanel, Sidebar, TextField, Textarea, TimePicker). Interactive behavior
(Tabs, Modal, Accordion, Dropdown, Stepper, Toast, Tooltip) comes from
`lepidus.js`. The full one-page showcase lives at
`packages/css/demo/index.html`.
